ASCII sculpture

How it's made: three.js draws a torus knot into a tiny hidden WebGL target; the pixels are read back and typed onto a Canvas 2D grid from a glyph sheet, so no text in the page changes. It turns by itself, you can drag it, and it stops when off-screen or in a hidden tab.
